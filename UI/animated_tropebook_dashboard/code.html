                            key
                            API Keys
                        

                        

                            

                                
                                

                                    
                                    
                                

                                

                                
Used for AI-powered prompt compression (gpt-4o-mini, $0.15/$0.60 per 1M input/output tokens) and semantic search embeddings (text-embedding-3-small, $0.02/1M tokens). Both are OpenAI's cheapest tier — typical usage runs fractions of a cent per call. Key is stored in your .env file — never sent to any third party except OpenAI.

                            

                            

                                
                                

                                    
                                    
                                

                                

                                
Brave dropped its free tier in Feb 2026 — it now requires a credit card and a $5 prepaid minimum, metered at roughly $0.003–$0.005/query with no spending cap. If that's a blocker, leave this unset: Tropelex tries Exa, then Serper, then DuckDuckGo automatically — see those two keys below for cheaper/free alternatives.

                            

                            

                                
                                

                                    
                                    
                                

                                

                                
Semantic web search — free tier around 1,000 searches/month, then pay-as-you-go (roughly $0.003–$0.005/search). Used automatically if Brave isn't configured; falls back to Serper, then DuckDuckGo.

                            

                            

                                
                                

                                    
                                    
                                

                                

                                
Google search results — 2,500 free queries up front (no card required), then from $50 for 50,000 queries ($1/1k, cheaper at higher volume). Used automatically if Brave and Exa aren't configured; falls back to DuckDuckGo.

                            

                            

                                No key configured? Tropelex falls back to DuckDuckGo — free, no signup, but rate-limits hard under repeated or automated use. Fine for occasional lookups; for anything more than light use, Exa's free tier or Serper's free queries above are more reliable at no cost. Pricing above is approximate and provider-set — it can change without notice (as Brave's did); check the provider's own pricing page before relying on it for budgeting.

                            

                                
                                

                                    
                                    
                                    
                                

                                

                                    
                                    

                                

                                
Use any OpenAI-compatible API (Ollama, vLLM, LiteLLM, etc.). Leave empty to use OpenAI.
