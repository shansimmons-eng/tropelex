# Tropelex Memory Viewer

VS Code extension for viewing and managing Tropelex project memory.

## Features

- View project memory files (`memory/*.json`) in the activity bar
- Open memory viewer panel
- Refresh memory data on demand

## Activation

The extension activates when your workspace contains files matching `**/memory/*.json`.

## Commands

- **Tropelex: Open Memory Viewer** - Opens the memory viewer panel
- **Tropelex: Refresh Memory** - Refreshes the loaded memory data

## Development

```bash
npm install
npm run compile
```

Press `F5` in VS Code to launch the Extension Development Host.
